Context

Not a revenue pitch. Built for public good, open source.

Shreevardhan's brother has cerebral palsy. On his phone he can open WhatsApp, scroll his chats, tap one region he can reliably reach, and record voice notes — anything else goes through Google Assistant, which took real training effort to recognize reliably.

Who's already served

Every existing tool assumes one clean channel.

If a person has……they can already use
No vision, good hand controlScreen reader (TalkBack / VoiceOver)
Motor difficulty, clear speech + sightVoice Access
Can reliably type or speak clearlyGeneral-purpose AI agents

Our target user has none of these individually — partial ability across more than one.

media/02-talkback-voiceaccess.mp4 (5–10s, clips 1&2)
The gap

No single tool. No cooperation between tools.

These users stitch together mismatched tools, or depend on a caregiver — losing independence on tasks they should manage alone.

Adaptive input already exists — as hardware. A foot-controlled trackball, a tongue-driven mouse. We do the same thing in software, on the phone already in their hand — no dedicated device to buy or fit.

Prior art

Free-text entry without speech or fine taps already has an answer.

Dasher (Cambridge / GNOME) — zooming, continuous-steer text entry. We cite it as evidence the gap is real; we don't rebuild it.

media/03-dasher.mp4 (5–10s, from dasher-project.github.io/dasher-web)
The model

A measured capability profile, not a disability label.

Continuous axes — touch precision, speech clarity, vision — measured from the real user, not assumed from a category.

Why this is defensible

The pieces exist separately. Nobody combines them live.

Continuous ability modeling and modality fusion both have academic precedent — what's new is doing it live, on a phone, with an agent closing the inference gap in real time.

To be clear: this isn't an AI product. Adaptive input is the core — AI only closes small inference gaps, always under confirmation.

Close

~$2.5B market today. Kept open source.

India's assistive-tech market is estimated at ~$2.5B today (IMARC), heading to ~$3.6B by 2034 — built open source so the adaptive layer can be adopted and localized, not gated.
